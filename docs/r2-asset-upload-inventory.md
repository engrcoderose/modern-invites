## How to use this list

- Start with large referenced photos and videos. Small logos, QR codes, icons, and fonts can stay local.
- Proposed R2 object keys preserve each client folder. Upload without the `app/` or `public/` prefix, using the proposed key. Existing website URLs do not change until the code is updated.
- Preserve photo dimensions, aspect ratios, alt text and existing image optimization when replacing static imports. Large source photos should not be served at full original size to every guest.
- Leslie and Serj's `opengraph-image.tsx` now fetches the opening logo/background from R2 and embeds them in the sharing preview; its font remains local.
- Do not delete local media yet. Verify the remote assets and update every reference first, then keep backups outside the repository.
- “Referenced” means a direct source path was found in application code or CSS; it does not prove the component is rendered. Dynamically assembled paths can be missed. No-reference files need review, not automatic upload or deletion.
