# Invitation artwork

- `garden.webp`: original decorative painting generated with the built-in image-generation tool, optimized to a 1024 × 1536 WebP. Exact prompt: `garden-prompt.txt`. It does not depict either actual venue. The full generated original remains in the generation tool's output folder.
- `attire-gentlemen.webp`, `attire-ladies.webp`: supplied illustrations extracted from pages 3 and 4 of the owner's `Wedding-Details.pdf`; optimized to WebP at quality 85, original dimensions retained.
- `security-bank-qr.jpg`, `gcash-qr.jpg`: original embedded images extracted unchanged from page 4 of that PDF. No payment payload was recreated or modified. The client should verify both QR codes and account details before publication.

Each shipping raster has embedded or adjacent generation/source provenance; the provenance tool uses JSON sidecars for WebP and JPEG comments for the original QR images. No couple photos or playable music file have been supplied.
