# Attire inspiration

Regenerated with the built-in image-generation tool from the user-supplied attire-guide reference. These are fashion illustrations, not the actual sponsors or guests. No CLI/API fallback or private credentials were used.

- `principal-sponsors-attire.png`: full-body old-rose gown and black suit with burgundy tie; 1254 × 1254 pixels, alpha transparency.
- `guest-outfit-inspiration.png`: ten semi-formal guest outfit examples; 2120 × 742 pixels, alpha transparency.
- `guest-outfit-inspiration-mobile.png`: the same ten outfit examples regenerated as two rows of five complete figures for phones; 1122 × 1402 pixels, alpha transparency.

The original generated PNGs remain in the Codex generated-images folder. These project copies retain their pixels and transparency. Static imports and the existing Next.js image optimizer provide responsive versions, lazy loading and content-hashed URLs.

The guest lineup is shown in one row on desktop, with a separately generated two-row composition on mobile so no outfit crosses a cropped boundary. Both compositions use responsive sizes and lazy loading; the visible composition follows the viewport. Labels, attire guidance and palette names are website text. Sponsor outfits and guest palette follow the supplied reference; the confirmed guest restriction on white and black shirts or dresses remains in `data/wedding.ts` and the FAQ.
