# Invitation fonts

## Fleur De Leah

The user selected Fleur De Leah for the invitation titles on November 1, 2026. `fleur-de-leah-latin.woff2` is the self-hosted Google Fonts Latin subset, normal style at weight 400. The invitation-scoped `--jb-title-font` applies it to the welcome and hero names, countdown names, section headings, entourage role headings, and RSVP title. Body copy and event details retain Noto Serif. The accompanying `fleur-de-leah-OFL.txt` preserves the font's copyright and SIL Open Font License.

Source CSS: https://fonts.googleapis.com/css2?family=Fleur+De+Leah&display=swap

Font source: https://github.com/google/fonts/tree/main/ofl/fleurdeleah

## Noto Serif

Self-hosted Latin WOFF2 files from Google Fonts, downloaded October 7, 2026. Both normal and italic files support weights 400–600. Their combined size is approximately 83 KiB. The Latin subset covers the invitation’s current English text, accented names, and punctuation.

Source CSS: https://fonts.googleapis.com/css2?family=Noto+Serif:ital,wght@0,400..600;1,400..600&display=swap

The accompanying `noto-serif-OFL.txt` contains the SIL Open Font License and original copyright notice. Keep it with the font files when distributing them. For future text in another script, add the appropriate subset.
