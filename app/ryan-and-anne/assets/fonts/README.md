# Invitation fonts

Mea Culpa (normal, weight 400) supplies the main headlines through the existing root layout’s `--font-mea-culpa` variable and `next/font/google` setup. No additional headline font is downloaded or duplicated in this client. The navigation uses the supplied monogram artwork.

Noto Serif (normal and italic, weights 400–600) supplies body copy and event details, plus the uppercase Our Story collage and invitation headings requested in the visual references. It is self-hosted with a client-specific family name.

Noto Serif Latin files reuse the repository’s licensed copies in `app/jaydee-and-bea/assets/fonts/`, originally obtained from:
https://fonts.googleapis.com/css2?family=Noto+Serif:ital,wght@0,400..600;1,400..600&display=swap

Keep the accompanying Noto Serif OFL license file with the fonts. The Latin subsets cover the invitation’s current text; add an appropriate subset if future content requires another script.

Roboto Mono (normal, weight 400) supplies the hero date, time, and location. Its Latin subset is self-hosted as `RA Roboto Mono`, downloaded from the official Google Fonts stylesheet:
https://fonts.googleapis.com/css2?family=Roboto+Mono:wght@400&display=swap

Keep `Roboto-Mono-OFL.txt` with the font.
